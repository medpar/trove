## How it works

```mermaid
flowchart LR
  subgraph Capture
    direction TB
    EXT[Browser extension<br/>pages, highlights, bookmarks,<br/>X bookmarks, Pinterest]
    PHONE[iPhone / iPad / Mac<br/>Shortcuts, iOS app]
    TG[Telegram bot]
    MAIL[Email]
    CLI[CLI, REST, MCP<br/>scripts and AI agents]
    SYNC[Feeds, GitHub stars,<br/>YouTube + Spotify]
  end

  subgraph Trove["Trove (Next.js on Vercel)"]
    direction TB
    API[API] --> EXTRACT[Extract<br/>Readability, transcripts,<br/>posts, READMEs, PDFs]
    EXTRACT --> ENRICH[Enrich<br/>AI filing, summary, OCR,<br/>embeddings, snapshot]
  end

  EXT & PHONE & TG & MAIL & CLI & SYNC --> API
  ENRICH --> NOTION[(Your Notion<br/>database)]
  ENRICH -.-> AI[Workers AI<br/>free tier]
  ENRICH -.-> WB[Wayback Machine]
  NOTION --> APP[Web app, iOS app,<br/>Raycast, CLI]
  NOTION -. nightly .-> BACKUP[(Markdown + JSON<br/>backup repo)]
```

Saving a link, step by step:

```mermaid
sequenceDiagram
  autonumber
  participant You
  participant Trove
  participant Notion
  participant AI as Workers AI
  You->>Trove: save a link (any device)
  Trove->>Trove: normalize URL, check for a duplicate
  Trove->>Trove: fetch and extract the content
  Trove->>Notion: page with text, cover and media
  Trove-->>You: saved ✓ (or merged into the existing one)
  Trove->>AI: suggest collection + tags, summarize, OCR, embed
  Trove->>Notion: filing, summary, page snapshot
```

## 📥 Save from everywhere

| Where | How |
|---|---|
| 🌐 **Web app** | Paste anywhere (<kbd>⌘V</kbd>), drop a link, or press <kbd>N</kbd>. Many links at once, or a note. |
| 🧩 **Brave / Chrome / Edge / Arc** | Toolbar, <kbd>Alt</kbd>+<kbd>Shift</kbd>+<kbd>S</kbd>, or right-click. Archives logged-in and paywalled pages, imports browser bookmarks, syncs **X bookmarks** and **Pinterest**. |
| 📱 **iPhone, iPad, Mac** | Four Shortcuts in the Share sheet (Settings → Ways to save), plus the native [iOS app](ios). |
| ✈️ **Telegram** | Send or forward anything to your bot. `#tags @Collection !fav`, buttons to edit, `? query` to search, `?? question` to ask. |
| ✉️ **Email** | Forward to your Trove address: newsletters become articles, attachments become files. |
| ⌨️ **Terminal and agents** | `trove` CLI, REST API and MCP. Agents can upload files too. |
| 📡 **Automatic** | RSS/Atom/Substack/YouTube feeds (OPML), GitHub stars twice a day, YouTube and Spotify progress hourly. |
| 🧷 **Anything else** | Raycast on Mac, the installable PWA on Android/Windows/ChromeOS, or a bookmarklet. |

<details>
<summary><b>What gets archived, per source</b></summary>

- **Articles** as clean text (Readability), with the cover image.
- **YouTube** with description and transcript.
- **X, Reddit, Bluesky, Mastodon, Hacker News** posts with text, media and thread or reply context.
- **GitHub** repos with their README. **arXiv** papers with abstract and the PDF.
- **PDFs, images, video and audio** files (up to 1 GB), with OCR for images and scans.
- **Every page** gets a self-contained snapshot in Notion and a Wayback Machine capture, one click away when the link dies.
- **Never a duplicate**: URLs are normalized (tracking params, `www`, mobile hosts, `youtu.be`, arXiv versions…), and saving again merges tags, notes and highlights.
</details>

<details>
<summary><b>Search operators</b></summary>

`"phrase"` · `-word` · `#tag` · `-#tag` · `type:video` · `site:github.com` · `collection:"Dev/AI"` · `is:fav` · `is:unread` · `created:>2025-01` · `highlights:true` · `source:x` · `match:OR`

Plain sentences in **All items** use hybrid search (keywords + meaning).
</details>

<details>
<summary><b>Telegram, email and Shows setup</b></summary>

**Telegram.** Create a bot with @BotFather and set `TELEGRAM_BOT_TOKEN`, `TELEGRAM_WEBHOOK_SECRET` (random) and `TELEGRAM_ALLOWED_USERS` (your numeric id) on Vercel. Then Settings → Ways to save → Telegram → Reconnect. Optional in @BotFather: `/setinline` for `@bot query` in any chat, and Guest Chat Mode so mentioning the bot in a chat saves that message.

**Email.** Deploy `workers/email` (`wrangler deploy`, `wrangler secret put TROVE_EMAIL_SECRET`), enable Cloudflare Email Routing on a **subdomain** so your main mail is untouched, and route an address to the worker. On Vercel set `TROVE_EMAIL_SECRET`, `TROVE_EMAIL_FROM` (allowed senders) and `TROVE_EMAIL_ADDRESS`.

**Shows.** Connect your Spotify and YouTube sign-ins (extension settings, or Trove → Settings → Shows). No Premium, no API keys. Details in [docs/shows.md](docs/shows.md).
</details>

## 🤖 For AI agents

Anything that can run a command or make an HTTP request can save to Trove and search it. Give it the CLI or the API and a key from Settings.

<img src="docs/screenshots/cli.webp" alt="The trove CLI: save, search and ask">

```bash
npm install -g github:medpar/trove
trove login --key <api key>
trove save https://example.com -t ai -n "why it matters"
trove upload ./screenshot.png ./demo.mp4 -c Design      # up to 1 GB
trove search '#ai type:article' --json
```

Every command takes `--json`, and the [skill file](skills/trove/SKILL.md) teaches skills-aware agents when to use it.

<details>
<summary><b>REST, files and MCP</b></summary>

- **REST:** `POST /api/items {url | text, tags, collection, note, highlight}`, `GET /api/items?q=…`, `GET /api/items/:id?content=1`.
- **Files:** `POST /api/files` with a multipart `file`, raw bytes, base64 `data` or a public `file_url` (up to 4 MB). Bigger files: `POST /api/files/uploads {filename, size}` returns a presigned URL; `PUT` the bytes, then `POST /api/files {upload}`. Same bytes again are merged.
- **MCP:** `https://<your app>/api/mcp` with `Authorization: Bearer <key>`, including `save_file` and `create_upload`.
- Docs: [`/llms.txt`](https://trove.mariomedpar.com/llms.txt) and [`/openapi.json`](https://trove.mariomedpar.com/openapi.json).
</details>

### The built-in librarian

Trove's own agent searches, tags, sorts, merges duplicate tags and summarizes. It runs **on your computer with your Claude Pro/Max or ChatGPT plan** through Claude Code or Codex (no API keys) and acts only through the `trove` CLI.

```bash
claude auth login                                   # or: codex login
trove agent "tag everything that has no tags"
trove agent install                                 # macOS: lets the web app's Agent panel use it
```

## 🛠 Self-host it

Everything runs on free tiers: **Vercel Hobby** + **your Notion** + **Cloudflare** (DNS, email routing, Workers AI).

```mermaid
flowchart LR
  A["① Notion<br/>setup script"] --> B["② Vercel<br/>deploy web/"] --> C["③ Extension<br/>load unpacked"] --> D["④ Optional<br/>AI, Shortcuts,<br/>Shows, backup"]
```

1. **Notion:** `node scripts/setup-trove.mjs` creates the database with every column (uses `NOTION_TOKEN` or the `ntn` CLI login).
2. **Vercel:** new project with root directory `web`. Set the variables below and deploy.
3. **Extension:** load `extension/` unpacked (or the [release zip](https://github.com/medpar/trove/releases/latest)), then set the app URL and API key in its settings.

<details>
<summary><b>Environment variables</b></summary>

| Variable | What |
|---|---|
| `NOTION_TOKEN`, `TROVE_LIBRARY_DS`, `TROVE_LIBRARY_DB` | Notion access and the database ids from the setup script |
| `TROVE_PASSWORD`, `TROVE_SESSION_SECRET` | Web app sign-in |
| `TROVE_API_KEYS` | `Name:key,Name:key` (more in `TROVE_API_KEY_<NAME>`); the name shows as **Via** |
| `TROVE_PUBLIC_URL`, `CRON_SECRET` | Public URL and the daily broken-link check |
| `BLOB_READ_WRITE_TOKEN` | Private Blob store for uploads over 4 MB (`vercel blob create-store trove-uploads --access private`) |
| `AI_BASE_URL`, `AI_API_KEY`, `AI_MODEL`, `AI_VISION_MODEL`, `AI_EMBED_MODEL` | Optional AI, see below. `TROVE_AI=off` disables it |
| `GITHUB_STARS_USER`, `GITHUB_TOKEN` | Optional GitHub stars sync |
| `TROVE_BACKUP_REPO` | Optional, links the backup repo from Settings |
</details>

<details>
<summary><b>Optional extras: AI, Shortcuts, Shows, backups</b></summary>

- **AI (free):** deploy `workers/ai` (`wrangler deploy`, `wrangler secret put TROVE_AI_SECRET`), then set `AI_BASE_URL` (worker URL + `/v1`), `AI_API_KEY`, `AI_MODEL=@cf/qwen/qwen3-30b-a3b-fp8`, `AI_VISION_MODEL=@cf/meta/llama-4-scout-17b-16e-instruct`, `AI_EMBED_MODEL=@cf/baai/bge-m3`. Optionally `wrangler secret put TROVE_ENRICH_KEY` so the worker processes waiting items every hour. The Workers Free plan stops at 10,000 neurons a day and can't bill. Without `AI_BASE_URL`, Trove uses Vercel AI Gateway (needs a card).
- **Shortcuts:** `python3 scripts/make-shortcut.py https://your-app` builds and signs all four.
- **Shows:** connect Spotify and YouTube, and redeploy `workers/ai` so its hourly cron syncs them ([docs/shows.md](docs/shows.md)).
- **Backup:** a private repo with `.github/workflows/backup.yml` running `trove backup library` nightly and a `TROVE_API_KEY` secret.
- **Coming from a separate X Bookmarks database?** `node scripts/merge-x-into-trove.mjs` moves those pages in.
</details>

<details>
<summary><b>How the X sync works</b></summary>

X's web API rotates query ids, feature flags and an `x-client-transaction-id`. The extension records the request templates your own x.com tabs send (via `webRequest`, no content scripts), reads current query ids from x.com's bundle, and replays them from the service worker with your cookies. No paid X API. Bookmarks are archived within seconds and every 30 minutes, with a full, resumable backfill. Media goes straight from X's CDN into Notion; your browser downloads nothing.
</details>
