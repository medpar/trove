Library

Everything in one place, organized like you'd want

Nested collections, tags, favorites, read later, notes, highlights and reminders. Cards, list, headlines or moodboard, light or dark, and keyboard-first.

  • Never a duplicate: links are normalized and saves merge.
  • Broken-link checks, with the archived copy one click away.
Reader

Read it later, even after it's gone

The archived text in a calm reader, with highlights and notes, listen aloud, and reading progress that syncs across devices. Every page also gets a snapshot and a Wayback Machine capture.

Ask & search

Ask your library a question

“What have I saved about offline sync?” gets an answer written from your own saves, with numbered sources. Plain sentences in search match by meaning, not just words.

Shows

What you watch on YouTube and listen to on Spotify, on any device, in one record per episode: what you actually played, where you stopped, and whether you finished. No Premium, no API keys.

On your phone, in your browser

An installable web app and a native iPhone/iPad app, plus an extension that saves the page you're on and tells you where you left off in a video.

For AI agents

Built to be driven by agents

Anything that can run a command or make an HTTP request can save to Trove and search it: the trove CLI, a REST API with OpenAPI docs, and an MCP server. Agents can upload images, video and documents too.

npm install -g github:medpar/trove
trove save https://example.com -t ai
trove ask "what did I save about pricing?"

Get started

Self-host it in a few minutes on free tiers. Full instructions are in the README.

  1. Notion: run node scripts/setup-trove.mjs to create your database.
  2. Vercel: deploy the web/ folder with your Notion token, a password and API keys.
  3. Extension: download the latest release, open chrome://extensions, turn on Developer mode and load it unpacked. Paste your app URL and key.
  4. Optional: free AI on Cloudflare Workers AI, Shortcuts, Telegram, email, Shows and nightly backups.
